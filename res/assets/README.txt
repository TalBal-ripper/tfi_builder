To launch the game, follow these steps:
1. Unzip the game's .zip archive
2. Open Terminal and enter the following code
xattr -cr /Applications/The\ Forgotten\ Island.app && codesign --force --deep --sign - /Applications/The\ Forgotten\ Island.app
____________________________________________________

Чтобы запустить игру, выполните следующие действия:
1. Распакуйте .zip архив с игрой
2. Откройте терминал и вставьте код
xattr -cr /Applications/The\ Forgotten\ Island.app && codesign --force --deep --sign - /Applications/The\ Forgotten\ Island.app
____________________________________________________

Para iniciar el juego, sigue estos pasos:
1. Descomprime el archivo .zip del juego
2. Abre el terminal e introduce el código
xattr -cr /Applications/The\ Forgotten\ Island.app && codesign --force --deep --sign - /Applications/The\ Forgotten\ Island.app
____________________________________________________

要运行游戏，请按照以下步骤操作：
1. 解压缩游戏的 .zip 压缩文件
2. 打开终端，并输入以下代码
xattr -cr /Applications/The\ Forgotten\ Island.app && codesign --force --deep --sign - /Applications/The\ Forgotten\ Island.app
